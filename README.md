# Certificate Hub

Build the MVP from the attached PRD: a production-ready certificate generation and distribution platform. Enable Lovable Cloud first for backend, authentication, storage, scheduled jobs, and email capability. Implement organizations and events, participant management with CSV upload, column validation and dynamic-field mapping, certificate template upload/designer with personalized generation and QR/unique verification IDs, a public verification page, delivery status tracking, and scheduled bulk certificate sending by event with configurable cadence. Implement role-based access: admin, organizer, viewer. Make the UI polished, responsive, PWA-ready, and structure all code/components/services for reuse. Use sample/demo data so the core flows are testable. Do not use unnecessary explanations.
